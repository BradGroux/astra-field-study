# Repeatable local collection prompt

Use the prompt below with a local coding assistant, or run the README commands yourself. Replace the two dates and output path before execution. Do not paste raw history into any conversation.

> Work locally in my Astra Field Study checkout. Read README.md, CONTRIBUTING.md, docs/privacy.md and docs/methodology.md. Collect my own retained Codex native response metadata from START_DATE through END_DATE inclusive in UTC using tools/collect.py, writing a new draft at OUTPUT_PATH outside this checkout and outside my Codex store. Use the model/client/effort settings I specify; keep uncertain client and effort values unknown. Run the example validation and local tests first. Do not upload or publish anything, read SQLite, alter history, install dependencies, or inspect/copy prompt or tool content for the output. Do not run a fallback collector if this format is unsupported. Report that limitation without printing raw lines, file paths from history or private identifiers. Show the allowlisted preview and explain that I must review the full JSON and give release/license consent myself. Leave both consent values false. Do not stage the draft or infer adherence observations from usage totals. If I later request observations, help me categorize my safely summarized local observations, including successful adherence and alternatives, without requesting raw logs. Stop after the local draft and checks; wait for my separate submission decision.

The collector parses JSON lines locally to reach metadata fields; a line may contain private text even though the code neither emits nor copies that text into the aggregate. Only run it where you are comfortable granting local read access. Run after relevant work has stopped writing logs. A partial trailing line causes a safe failure; retry after writes finish. Do not edit source history to make the collector pass.

Choose a bounded date range that matches the work you want to describe. Collection itself may appear in current-day history; use a completed earlier window if you want to avoid that overlap. End dates are inclusive UTC days, not an assertion that every hour of the day was observed. Retention gaps and ongoing work limit coverage. Do not treat a missing record as zero account usage.
