## v1.0 — 2026-09-09

The first complete public study package includes a local collection and contribution kit, reviewed observational evidence, reproducible reader data, six exportable SVG/PNG figures, and an interactive explorer with an optional 3D view.

### Final documentation update

The main README, evidence guide, reader guide, and source references now link to the published written resources. Editorial source and social drafts remain in digitalmeld.io; this repository retains the evidence, methods, figures, explorer, and contribution kit.

The frozen case contains 25,254 recorded responses across 557 turns and 538 substantive contributions: 147 corrective, 154 expressing dissatisfaction, and 91 in both categories. There are 78 correction episodes, including 31 with repeated corrections. Recorded tokens total 3,420,584,663, including 3,348,480,640 cached input tokens. These counts describe activity and reviewed contributions, not a model failure rate, cost, or productivity gain.

### Compatibility and limits

This v1.0 package label does not rename or revise data formats. The frozen case remains evidence version 1 in observational evidence format 1.0. Participant submission schemas 1.0 and 1.1 remain supported; 1.1 adds optional direct satisfaction and ease ratings. No retrospective ratings are inferred from this case.

No measurements, classifications, schemas, collector behavior, or reader code change in this documentation update. Both causal hypotheses remain untested, and no matched GPT-5.6/GPT-6 comparison is claimed. Raw conversations and private provenance remain private. Successful adherence and contradictory experiences are welcome through the contribution process.
