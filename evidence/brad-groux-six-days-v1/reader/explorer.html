Definitions, sources, and limits

This local candidate uses only the versioned evidence file and a reproducible derived reader dataset. All projects are aliased, with relative days and no raw transcripts, task identifiers, machine paths or mappings. De-identification does not guarantee anonymity.

  • Recorded usage: reconciled retained records, common cutoff, three measurement/coordination tasks excluded. This is not an account billing export.
  • Coded observations: 538 substantive contributions, with typed and voice components reconciled. Native message items use a different denominator.
  • Repository activity: complete net boundary diffs and timestamped events across 17 identifiable repositories. Activity is not quality or model authorship.
  • Task counts and runtime unions are omitted from filtered totals because they are not additive.
