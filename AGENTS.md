# Repository instructions

Preserve the distinction between measured descriptive activity and untested causal hypotheses. Invite contrary evidence and successful adherence examples. Never claim that efficiency itself is cheating.

Keep private history out of this public repository. Only allowlisted, manually reviewed aggregate contributions may enter submissions. Use synthetic fixtures for collector tests. Do not include raw logs, prompts, SQLite, credentials, private repository names/paths or original identifiers, even as hashes. Do not copy local audit evidence into examples.

Use Python standard library and run tests/validation locally. Never add, enable, trigger or require GitHub Actions or connected third-party CI. Inspect automation triggers before publication actions. No production dependencies without explicit approval. No automatic uploads or consent on a contributor's behalf.

Original code, docs and contributed datasets use MIT. Preserve copyright and permission notices. Third-party linked content keeps its own terms.
